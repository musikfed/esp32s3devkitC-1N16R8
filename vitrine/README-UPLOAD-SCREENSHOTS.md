# Два настоящих экрана MultiBoard Studio

Проект — **прошивка, программирование, отладка GPIO, версии и тестирование микроконтроллеров ESP32-C3/S3**, а **не умный дом**.

- `vitrine/screenshots/main.jpg`: реальный скриншот режима Studio / контроля версий (уже находится в этой ветке; Git blob совпадает с переданным автором оригиналом).
- `vitrine/screenshots/gpio-and-versions.jpg`: второй авторский скриншот с матрицей GPIO (путь записан в meta.json, но файл ещё необходимо загрузить).

Чтобы добавить второй экран, скачай из беседы `PLCodeStore_esp32s3devkitC-1N16R8_screenshots.zip`, распакуй, переключись на ветку `plcodestore/vitrine-proposal`, открой `vitrine/screenshots/`, нажми **Add file → Upload files** и загрузи `gpio-and-versions.jpg`.

В ZIP лежит также защищённая копия `main.jpg` с размытыми локальными IP-адресами — её можно использовать для замены нынешней главной картинки перед публикацией. Оригинал в ветке не меняем автоматически без авторского решения.

Оба скриншота реальные, не сгенерированные картинки. После проверки можешь объединить PR.
